How it works · the agents

Four agents. One pull request.

  1. Plannerbig model

    Turns the issue into a plan.

    1. Reading the issue
    2. Plan: 3 tasks, 12 tests
  2. Builderfast model

    Writes the change.

    1. Waiting for the plan
    2. Writing the date parser
    3. Reading the failure
    4. Fix pushed: time zones
  3. Testersmall model

    Writes and runs the tests.

    1. Waiting for the plan
    2. Writing 12 tests
    3. 1 of 12 fails: time zones
    4. 12 of 12 pass
  4. Reviewerother lab

    Reads the diff cold.

    1. Waiting for green tests
    2. Reading the diff
    3. Approved, one nit

7:00–8:00. One task, four agents. Space moves the story on: the plan, building and testing side by side, a failing test and its fix, then the review.
