Order flow

An order moves through four stages

  1. ReceiveTake the message off the queue and find who sent it.
  2. GuessWork out which items the message is asking for.
  3. ConfirmReply with the order read back, in plain words.
  4. PickPut it on the packing list for the morning.

6:00–7:00. Press Space once per stage and say one sentence for it; the marker moves to the stage you’re on.

Stages are numbered by CSS. With data-step the last revealed card is the current one, via :has(). Without steps, add is-current to the card to light.
