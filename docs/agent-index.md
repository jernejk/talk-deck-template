# Agent index

Generated by `npm run build` from `slides/index.json`, the pattern files and `docs/components.md`. Don't edit it; run `npm run build` to refresh it.

Pick patterns here, then open only the files you need: `slides/<name>.html`, and the component rows in `docs/components.md`. `npm run add -- <deck> <name>` copies a pattern into a deck. Vary the layout between neighbouring slides. Names starting with `x-` are presenter extras.
